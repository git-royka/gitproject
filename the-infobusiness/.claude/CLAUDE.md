# Контекст проєкту: календар подій для Telegram-клубу (Mini App)

## Що це

Закритий Telegram-клуб з форум-гілками (topics). Складається з трьох частин:
1. Закріплений пост-путівник для нових учасників (ще не написаний/не опублікований)
2. Telegram Mini App — стрічка подій місяця (без сітки-календаря): перемикання місяців стрілками, тема місяця під назвою, нижче список подій з датою/часом/фото/описом, кольорове кодування типів подій, кліком по події — перехід у конкретне повідомлення в потрібній гілці
3. Бот (Telegraf), що вітає новачків путівником і показує календар по команді `/calendar`

Репозиторій: `https://github.com/git-royka/gitproject` (гілка `master`).
Робоча папка: `the-infobusiness/` в корені репо (файли лежать flat, без підпапок `miniapp/`/`bot/`).

## Файли

### `the-infobusiness/index.html`
Статичний HTML/JS без білд-кроку, задеплоєний на Vercel: **https://the-infobusiness-calendar.vercel.app/**
- `telegram-web-app.js` (CDN) для теми й `openTelegramLink()`
- PapaParse (CDN) тягне події з опублікованої як CSV Google Таблиці
- **UI (з 2026-09-10): без сітки-календаря.** Шапка — стрілки ‹›, назва місяця, під нею тема місяця (`MONTH_THEMES`, ключ — номер місяця 0–11). Нижче — стрічка (`#feed`) усіх подій обраного місяця, згруповані по даті (`feed-day-section` / `feed-day-label`), кожна подія — картка з кольоровою крапкою типу, назвою, часом, фото (`summary-media`) і описом
- Посилання на повідомлення: `https://t.me/c/<chat_id_без_-100>/<thread_id>/<message_id>`

Налаштування вгорі файлу — **вже заповнені реальними значеннями**:
```js
const SHEET_CSV_URL = "https://docs.google.com/spreadsheets/d/e/2PACX-1vRNVvcFM2b1rwEbHu2TGk8Yx92GM8aVzs5sB727h8PRsRwV4xMWixHGe5QSf13jcyYEP_2-v3ed9Ex3/pub?gid=409438120&single=true&output=csv";
const CHAT_ID = "-1004459521892";
```

Теми місяців (`MONTH_THEMES` в `index.html`) — заповнені для вересня–січня:
вересень «АІ в інфобізнесі», жовтень «Воронки, що продають», листопад «Продажі та конверсія», грудень «Системний інфобізнес», січень «Трафік і масштабування». Інші місяці без теми (рядок порожній).

### `the-infobusiness/events-template.csv`
Шаблон/референс структури таблиці подій (не використовується напряму рантаймом — джерело даних це опублікований Google Sheets CSV вище). Колонки:
```
date,title,type,time,thread_id,message_id
2026-08-12,Офлайн-зустріч у Києві,offline,18:30,16,41
2026-08-20,Онлайн-розбір домашки,online,19:00,16,41
2026-08-27,Прямий ефір з гостем,stream,20:00,16,41
```

### `the-infobusiness/bot.js` (Node.js, Telegraf)
- Вітає нових учасників групи повідомленням-путівником з кнопкою "Календар подій" (web_app button)
- Команда `/calendar` — показує ту саму кнопку будь-де в чаті
- Токен бота і URL Mini App читаються з `.env` (НЕ комітяться в git)

### `the-infobusiness/package.json`
Залежності: `telegraf`, `dotenv`. `npm start` → `node bot.js`.

## Реальна Google Таблиця

Назва: **"The InfoBusiness_Calendar"**, аркуш **"events-template"**, `gid=409438120`.
Наразі містить лише 3 тестові рядки (див. CSV вище) — треба буде наповнити реальними подіями клубу.

## Відомі реальні значення чату

- Chat internal ID: `4459521892` → повний `chat_id` для Bot API: `-1004459521892`
- Приклад гілки: `https://t.me/c/4459521892/16`  → `thread_id = 16`
- Приклад повідомлення в цій гілці: `https://t.me/c/4459521892/16/41` → `message_id = 41` (тестове значення, використане у всіх 3 тестових подіях)

## Git-історія цієї роботи (для контексту, не для повторення)

1. Закомічено й запушено початковий скелет (`bot.js`, `index.html`, `package.json`) — комміт `f54fa24`
2. Створено `events-template.csv`, користувач імпортував його в Google Sheets і опублікував як CSV
3. Вписано реальний `SHEET_CSV_URL` і `CHAT_ID` в `index.html`, локально перевірено в браузері (`python3 -m http.server`) — рендериться коректно
4. Закомічено й запушено ці зміни — комміт `119d7a2`, запушено в `origin/master`
5. Далі, у попередніх сесіях: правки шторки/скролу, узгодження місяців у датах (родовий відмінок), додано заголовок секції з датою найближчої події, картка найближчої події під календарем, автовидалення службових повідомлень форуму про закриття/відкриття теми — коміти `f6e6c54`, `e920fdf`, `4482efb`, `f817fe8`, `c93de22`

7. Перевірено `curl https://the-infobusiness-calendar.vercel.app/` — Vercel підхопив автодеплой `5c24859`, на проді вже новий `#feed`-UI і актуальний `SHEET_CSV_URL`

## Що ще не зроблено / наступні кроки

1. Наповнити Google Таблицю реальними подіями клубу (замість тестових рядків)
2. Деплой бота (`bot.js`) на постійний хостинг (Railway/Render) — зараз є тільки локальний код
3. **BotFather**: прив'язати Mini App до бота командою `/newapp` (URL — https://the-infobusiness-calendar.vercel.app/)
4. Написати й закріпити пост-навігацію в групі з посиланнями на гілки

## Технічні рішення (свідомо обрані, не змінювати без потреби)

- Статичний HTML без білд-кроку (не React) — простіше деплоїти, менше залежностей
- Дані подій через публічний CSV з Google Sheets, а не API з ключем — щоб уникнути серверної частини й спростити ротацію подій нетехнічним адміном клубу
- `thread_id` дорівнює номеру найпершого повідомлення гілки (стандартна поведінка Telegram forum topics)
- Токен бота — тільки в `.env` бота, ніколи в коді фронтенду
